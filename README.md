# Contact Form

A simple accessible HTML contact form built using semantic HTML

## Features

- Accesible form controls with labels
- Browser validation using HTML attributes
- Required Fields
- Email verification
- Subject dropdown menu
- Message textarea with minimum length validation
- Radio button group inside a fieldset and legend
- Optional newsletter subscription checkbox
- Submit button

## Technologies Used

- HTML5

## Project Structure

contact-form/
├── index.html
└── README.md

## Form Fields

- Full Name (required)
- Email (required)
- Subject (select menu)
- Message (required, minimum lenght)
- How did you hear about us? (readio buttons)
- Newsletter subscription (checkbox)


## Learning Objectives

- Building accessible form
- Associating labels with form controls
- Using broswer validation attributes
- Grouping related controls with fieldset and legend
- Understanding how form submissions create HTTP requests
